# 技术风险清单

## P0：必须优先验证

| 风险 | 类型 | 严重程度 | 问题 | 建议 |
|---|---|---:|---|---|
| 对象分割不稳定 | AI（Artificial Intelligence，人工智能） | ★★★★★ | 点不到用户真正想改的对象 | 多模型 + 交互式分割 + 手工修正 |
| 毛发边缘 | 算法 | ★★★★★ | 头发、动物毛发容易锯齿/缺失 | Image Matting（Image Matting，图像透明度估计） |
| 半透明对象 | 算法 | ★★★★★ | 玻璃、婚纱、水、烟难分割 | Alpha Matting（Alpha Matting，透明度估计），需要技术验证 |
| 大图内存 | 工程 | ★★★★★ | 多图层很快数 GB（Gigabyte，十亿字节级存储单位） | Tile（Tile，图像分块）+ 缓存 |
| Undo/Redo | 工程 | ★★★★★ | 保存整图会爆内存 | Command Pattern（Command Pattern，命令模式）+ 差量 |
| 对象移动后补背景 | AI（Artificial Intelligence，人工智能） | ★★★★★ | 空洞背景可能生成错误 | Inpainting（Inpainting，图像补全）+ 生成式补全 |

## P1：高风险

| 风险 | 类型 | 严重程度 | 建议 |
|---|---|---:|---|
| 对象遮挡 | 算法 | ★★★★ | 建立 Layer Ordering（Layer Ordering，层级顺序估计） |
| 阴影重建 | 算法 | ★★★★★ | V1 简化，后续再做 |
| 反射重建 | 算法 | ★★★★★ | V1 不承诺完全自动 |
| 本地模型速度 | 性能 | ★★★★ | ONNX Runtime（Open Neural Network Exchange Runtime，开放神经网络交换格式运行时）+ GPU |
| 低端显卡 | 性能 | ★★★★ | 中央处理器降级路径 + 模型分级 |
| 模型体积 | 产品 | ★★★ | 模型按需下载 |
| 生成结果不可控 | AI（Artificial Intelligence，人工智能） | ★★★★ | 多结果 + 可回退 |
| 云端成本 | 商业 | ★★★★ | 生成式能力计费/额度 |
| 不同显卡驱动 | 工程 | ★★★★ | 建立兼容测试矩阵 |
| 图像颜色一致性 | 工程 | ★★★★ | ICC（International Color Consortium，国际色彩联盟）后续逐步支持 |

## P2：后期风险

- PSD（Photoshop Document，Photoshop 文档格式）兼容；
- RAW（RAW，相机原始图像格式）兼容；
- 专业色彩管理；
- 文字字体精确匹配；
- 印刷输出；
- 插件系统；
- 第三方模型兼容。

## 合规风险

- 删除版权水印；
- 生成内容版权；
- 人脸编辑；
- 云端上传隐私；
- 商业模型许可证；
- 开源模型许可证。

这些在正式商业化前必须进行法律和许可证审查。
