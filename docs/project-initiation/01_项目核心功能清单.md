# 项目核心功能清单

## 1. 基础图片能力

1. 打开图片
2. 保存项目
3. 导出图片
4. 裁剪
5. 旋转
6. 调整图片尺寸
7. 基础亮度
8. 基础颜色

## 2. 对象级核心能力

1. 自动对象识别
2. 鼠标悬停对象高亮
3. 点击选择对象
4. 对象 Mask（Mask，遮罩）生成
5. 对象移动
6. 对象缩放
7. 对象旋转
8. 对象删除
9. 对象换色
10. 对象透明化

## 3. 人物能力

1. 人物识别
2. 人物抠图
3. 背景移除
4. 背景替换
5. 背景虚化
6. 人脸识别
7. 人脸关键点
8. 肤色调整
9. 皮肤优化
10. 瘦脸
11. 人物增强
12. 衣服区域识别
13. 衣服换色

## 4. 场景能力

1. 天空识别
2. 天空替换
3. 天空颜色调整
4. 背景对象识别
5. 路人识别
6. 路人删除
7. Depth Estimation（Depth Estimation，深度估计）
8. 光照匹配
9. 阴影估计

## 5. 文字能力

1. OCR（Optical Character Recognition，光学字符识别）
2. 文字区域检测
3. 原文字移除
4. 新文字输入
5. 字体近似匹配
6. 文字颜色修改
7. 文字大小修改
8. 文字移动

## 6. AI（Artificial Intelligence，人工智能）能力

1. 目标检测
2. 实例分割
3. 语义分割
4. Image Matting（Image Matting，图像透明度估计）
5. Inpainting（Inpainting，图像补全）
6. 生成式填充
7. 生成式扩图
8. 超分辨率
9. 图像增强
10. 图像降噪

## 7. 底层必须长期保留的核心

1. Document Model（Document Model，文档模型）
2. Layer System（Layer System，图层系统）
3. Mask System（Mask System，遮罩系统）
4. Semantic Object System（Semantic Object System，语义对象系统）
5. Transform System（Transform System，变换系统）
6. History System（History System，历史系统）
7. Tile System（Tile System，图像分块系统）
8. Render Engine（Render Engine，渲染引擎）
9. AI Task Orchestrator（Artificial Intelligence Task Orchestrator，人工智能任务编排器）
10. Cache System（Cache System，缓存系统）
