# 技术选型建议

## 1. 推荐结论

### 小团队 MVP（Minimum Viable Product，最小可行产品）

```text
Flutter Desktop（Flutter Desktop，Flutter 桌面框架）
        │
FFI（Foreign Function Interface，外部函数接口）
        │
C++ Core（C++ 核心）
        │
├── Skia
├── OpenCV（Open Source Computer Vision Library，开源计算机视觉库）
├── ONNX Runtime（Open Neural Network Exchange Runtime，开放神经网络交换格式运行时）
└── GPU（Graphics Processing Unit，图形处理器）
```

### 长期专业版本

```text
Qt
+
C++
+
Skia
+
OpenCV（Open Source Computer Vision Library，开源计算机视觉库）
+
ONNX Runtime（Open Neural Network Exchange Runtime，开放神经网络交换格式运行时）
```

## 2. 技术角色表

| 技术 | 推荐用途 | 推荐度 | 说明 |
|---|---|---:|---|
| C++ | 核心图像引擎 | ★★★★★ | 性能、生态、图形和 AI（Artificial Intelligence，人工智能）集成成熟 |
| Rust | 底层安全系统 | ★★★ | 可用，但第一版不建议和 C++ 同时引入 |
| Flutter Desktop | UI（User Interface，用户界面） | ★★★★ | 小团队开发效率高 |
| Qt | 专业桌面 UI + 图形 | ★★★★★ | 长期版本稳健 |
| Electron | 快速桌面壳 | ★★ | 大图和专业编辑器性能不占优 |
| Tauri | 轻量桌面壳 | ★★★ | 适合 Web 前端团队，但仍需独立图像核心 |
| Skia | 二维渲染 | ★★★★★ | 图像、路径、文字、混合成熟 |
| OpenCV | 传统图像算法 | ★★★★★ | 不应重复造轮子 |
| ONNX Runtime | 本地模型推理 | ★★★★★ | 跨硬件部署统一 |
| PyTorch | 模型研发 | ★★★★★ | 用于训练、验证和导出模型 |
| TensorFlow | 模型研发/部署 | ★★★ | 可选，不建议同时维护两套训练生态 |
| WebGPU | Web 图形计算 | ★★★ | 桌面原生第一版非核心 |
| DirectX | Windows GPU | ★★★★★ | Windows 原生高性能 |
| Metal | macOS GPU | ★★★★★ | macOS 原生高性能 |
| Vulkan | 跨平台 GPU | ★★★★ | 功能强但工程复杂 |
| OpenGL | 兼容图形后端 | ★★★ | 可作为兼容层 |

## 3. 核心图像引擎建议

必须自主开发：

- 文档模型；
- 图层系统；
- Mask（Mask，遮罩）系统；
- 语义对象系统；
- Undo/Redo（Undo/Redo，撤销/重做）系统；
- Tile（Tile，图像分块）系统；
- 缓存系统；
- 任务调度；
- 对象交互；
- 非破坏式编辑。

## 4. 可使用成熟开源能力

- JPEG（Joint Photographic Experts Group，常用有损图片格式）/PNG（Portable Network Graphics，便携式网络图形格式）/WebP（WebP，网络图片格式）编解码；
- 基础缩放；
- 高斯模糊；
- 锐化；
- 颜色空间转换；
- 仿射变换；
- 透视变换；
- 图像形态学；
- 边缘检测；
- 直方图；
- 传统 Inpainting（Inpainting，图像补全）。

## 5. AI（Artificial Intelligence，人工智能）部署建议

### 本地

- 对象检测；
- 人像分割；
- 人脸检测；
- 人脸关键点；
- OCR（Optical Character Recognition，光学字符识别）；
- 背景移除；
- 基础超分辨率；
- 图像增强。

### 云端

- 高质量生成式填充；
- 生成式扩图；
- 复杂对象删除；
- 场景重建；
- 光照重建；
- 高质量对象替换。

## 6. 性能架构

必须考虑：

- Tile（Tile，图像分块）；
- 多分辨率预览；
- GPU（Graphics Processing Unit，图形处理器）加速；
- 延迟高质量计算；
- 内存预算；
- 显存预算；
- 缓存淘汰；
- Command Pattern（Command Pattern，命令模式）历史记录。

## 7. 第一阶段技术验证优先级

P0：

1. 对象识别；
2. Mask（Mask，遮罩）质量；
3. 人物抠图；
4. 对象移动；
5. 背景修补；
6. 4K（4K，约四千像素级分辨率）图片性能；
7. Undo/Redo（Undo/Redo，撤销/重做）。

P1：

1. 文字修改；
2. 衣服换色；
3. 天空替换；
4. 超分辨率；
5. 生成式扩图。
