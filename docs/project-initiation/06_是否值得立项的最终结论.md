# 是否值得立项的最终结论

## 结论

> **建议立项。**

但项目不应该定义为“傻瓜版 Photoshop”。

更准确的定义是：

> **对象驱动型智能图像编辑器。**

## 为什么值得做

### 1. 技术条件已经具备

人物分割、背景移除、目标检测、图像补全、超分辨率、OCR（Optical Character Recognition，光学字符识别）、生成式填充和扩图等能力已经具备较成熟的技术基础。

### 2. 用户需求真实存在

大量普通用户需要：

- 抠图；
- 删除；
- 换背景；
- 调颜色；
- 人像美容；
- 修复照片；
- 修改文字；
- 合成；
- 扩图；
- 商品图；
- 证件照。

但他们不愿意学习完整 Photoshop 工作流。

### 3. 真正的机会不是重新做 Photoshop

竞争壁垒不应该是“工具数量”，而应该是：

- Semantic Object System（Semantic Object System，语义对象系统）；
- Non-destructive Editing（Non-destructive Editing，非破坏式编辑）；
- Object Interaction（Object Interaction，对象交互）；
- AI Task Orchestrator（Artificial Intelligence Task Orchestrator，人工智能任务编排器）；
- 普通用户语言体系。

## 最大风险

1. 对象识别稳定性；
2. 毛发和半透明边缘；
3. 删除/移动后的场景补全；
4. 大图和多图层性能；
5. AI（Artificial Intelligence，人工智能）生成结果不确定性。

## PSD（Photoshop Document，Photoshop 文档格式）建议

V1 不做。

先建立自有项目文件格式和内部对象模型，等核心产品验证后再考虑 PSD 基础兼容。

## 自研与复用边界

### 自研

- 文档系统；
- 语义对象系统；
- 图层系统；
- Mask（Mask，遮罩）系统；
- Undo/Redo（Undo/Redo，撤销/重做）；
- Tile（Tile，图像分块）；
- 编辑流水线；
- AI（Artificial Intelligence，人工智能）任务编排；
- 对象驱动交互。

### 复用

- OpenCV（Open Source Computer Vision Library，开源计算机视觉库）；
- Skia；
- ONNX Runtime（Open Neural Network Exchange Runtime，开放神经网络交换格式运行时）；
- JPEG/PNG/WebP 编解码；
- 成熟 AI（Artificial Intelligence，人工智能）模型；
- 云端生成式服务。

## 第一版合理范围

15～20 个用户可见能力。

如果只有 1～3 名开发人员：

- 不做 PSD；
- 不做 RAW；
- 不做专业印刷；
- 不做视频；
- 不做插件；
- 不做专业钢笔；
- 不追求复杂商业合成。

先验证：

> **“用户点击对象，软件理解对象，然后直接执行目标”是否真的比 Photoshop 工具逻辑更易用。**

## 最终产品定义

> **这不是一个简化版 Photoshop，而是一套基于对象识别、语义图层、AI（Artificial Intelligence，人工智能）图像处理和目标驱动交互的新一代图像编辑器。**

最终用户体验应该是：

```text
我要改什么？
↓
点击它
↓
我要它变成什么？
↓
软件自动完成
```

如果这个核心体验成立，就有机会真正实现：

> **“不会 Photoshop 的人，也能完成过去需要 Photoshop 专业操作才能完成的大量图片处理任务。”**
