> 文档版本：V1.0

> 核心方向：对象驱动、目标驱动、语义图层、人工智能辅助、非破坏式编辑

# 0. 项目摘要

本项目拟开发一款面向普通用户、非设计专业用户以及 Photoshop（Adobe Photoshop，专业图像处理软件）零基础用户的桌面图像编辑软件。

项目不以“复制一个功能更少的 Photoshop”为目标，而是尝试重新设计传统图像编辑软件的人机交互逻辑：

传统 Photoshop：

```text
用户知道目标
↓
用户判断应该使用什么工具
↓
建立选区
↓
建立图层
↓
建立 Mask（Mask，遮罩）
↓
调参数
↓
组合多个工具
↓
得到结果
```

本项目：

```text
用户知道目标
↓
点击图片中的对象
↓
系统理解“这是什么”
↓
系统理解“用户能对它做什么”
↓
用户选择目标
↓
系统自动组织底层图像处理流程
↓
得到结果
```

例如：

```text
点击人物
↓
系统识别人像
↓
自动生成精细遮罩
↓
显示：

抠出人物
删除人物
更换背景
移动人物
改变大小
调整肤色
美化皮肤
修改衣服颜色
调整人物亮度
增强人物清晰度
```

用户不需要理解图层、选区、通道、曲线、色阶、遮罩、羽化、混合模式、钢笔路径、高反差保留、智能对象，但这些专业能力仍然存在于软件内部。

因此，本项目的核心产品定义是：

> **这不是一个简化版 Photoshop，而是一套基于对象识别、语义图层、智能图像处理和目标驱动交互的新一代图像编辑器。**

# 一、项目背景与立项目的

## 1.1 Photoshop 为什么对普通用户学习成本高

Photoshop 的主要困难并不是“按钮太多”，真正的困难在于其操作模型要求用户首先掌握一套图像处理抽象体系。

普通用户想的是：

> “把这个人删掉。”

Photoshop 要求用户思考：

```text
如何选择人物？
↓
使用对象选择还是套索？
↓
选区是否需要扩大？
↓
边缘是否需要羽化？
↓
删除后背景如何补？
↓
使用内容识别填充还是生成式填充？
↓
是否建立新图层？
↓
是否需要遮罩？
```

因此 Photoshop 的学习成本主要来自五个方面：

| 原因 | 本质 |
|---|---|
| 工具抽象 | 用户必须学习“怎么做”，而不是只表达“想做什么” |
| 专业概念 | 图层、通道、遮罩、路径、颜色空间都是专业抽象 |
| 参数复杂 | 容差、羽化、半径、阈值、Gamma（Gamma，伽马）等缺乏生活语言映射 |
| 工作流组合 | 很多高级效果不是一个按钮完成，而是多个工具组合 |
| 状态复杂 | 当前图层、当前选区、当前遮罩、当前工具会影响操作结果 |

## 1.2 Photoshop 的核心设计思想

Photoshop 本质上是一个通用、开放、低限制、可组合的二维图像处理工作台。

它提供像素、图层、选区、遮罩、路径、颜色运算、几何变换、滤镜、混合和脚本，再允许专业用户自由组合。

这种设计的最大优势是自由度极高，同时也是学习成本高的根本原因。

## 1.3 普通用户真正需要什么

普通用户通常不需要工具，而需要结果。

| 用户语言 | Photoshop 专业过程 |
|---|---|
| 删掉这个人 | 选区 + 遮罩扩大 + 图像补全 |
| 衣服变黑 | 分割 + 色彩转换 + 明暗保持 |
| 天空蓝一点 | 天空分割 + 色相/饱和度调整 |
| 背景虚一点 | 主体分割 + 景深模拟 |
| 人清楚一点 | 主体遮罩 + 局部锐化 |
| 图片横一点 | 扩展画布 + 图像生成 |
| 把字改掉 | 文字检测 + 文字移除 + 字体分析 + 重绘 |
| 人放大一点 | 分割 + 几何变换 + 背景补全 |

因此产品应该建立：

```text
用户意图
↓
自动任务规划
↓
图像处理流水线
```

## 1.4 项目核心定位

推荐定位：

> **面向普通用户的对象级智能图像编辑器。**

核心关键词：

- 点击即理解；
- 对象级编辑；
- 目标级操作；
- 自动选择；
- 自动遮罩；
- 自动边缘处理；
- 自动算法编排；
- 非破坏式；
- 随时恢复；
- 专业能力隐藏；
- 必要时允许微调。

# 四、Photoshop 各功能背后的技术原理

## 4.1 选区

选区不是“虚线框”，本质上是一张与图像对应的灰度权重图。

```text
0   = 完全不选
0.5 = 选择 50%
1   = 完全选择
```

因此选区的底层就是一种 Mask（Mask，遮罩）。

## 4.2 遮罩

假设：

```text
原图像 = C
遮罩 = M
背景 = B
```

最终图像近似：

```text
Output = C × M + B × (1 - M)
```

所以抠图本质上是求一张高质量 Mask（Mask，遮罩）。

## 4.3 图层

图层可抽象为：

```text
Layer {
    PixelData
    Mask
    Transform
    Opacity
    BlendMode
    Effects
}
```

多个图层按照 Z 轴顺序逐层合成，本质上是二维场景图。

## 4.4 混合模式

本质：

```text
输出像素 = f(上层像素, 下层像素)
```

Multiply（Multiply，正片叠底）可以近似理解为：

```text
C = A × B
```

Screen（Screen，滤色）近似：

```text
C = 1 - (1-A)(1-B)
```

## 4.5 曲线

输入亮度：

```text
x = 0～255
```

经过函数：

```text
y = f(x)
```

重新映射。工程上可以预计算成 Lookup Table（Lookup Table，查找表）。

## 4.6 色阶

重新定义黑点、白点和中间调，本质是分段线性映射 + Gamma（Gamma，伽马）调整。

## 4.7 饱和度

通常将颜色转换到 HSV（Hue Saturation Value，色相饱和度明度颜色空间）或类似颜色空间后修改 Saturation（Saturation，饱和度）分量。

## 4.8 模糊

基础模糊本质是邻域像素加权平均。高斯模糊使用 Gaussian Kernel（Gaussian Kernel，高斯卷积核）做卷积。

## 4.9 锐化

经典流程：

```text
原图
↓
模糊图
↓
原图 - 模糊图
↓
得到高频细节
↓
高频 × 强度
↓
加回原图
```

## 4.10 磨皮

```text
检测皮肤
↓
保护五官和边缘
↓
平滑皮肤
↓
保留纹理
↓
重新融合
```

可使用双边滤波、导向滤波、频率分离、人像分割和深度学习模型。

## 4.11 液化

液化本质是二维像素坐标位移：

```text
(x,y)
↓
位移场
↓
(x + dx, y + dy)
```

## 4.12 自由变换

平移、旋转、缩放本质是矩阵变换 + 像素插值。

## 4.13 透视变换

核心是 Homography（Homography，单应性变换），用于四边形到四边形的映射。

## 4.14 内容识别填充

```text
待删除 Mask（Mask，遮罩）
↓
搜索周围纹理
↓
寻找匹配图像块
↓
重建目标区域
↓
边缘/颜色融合
```

## 4.15 生成式填充

```text
原图
+
Mask（Mask，遮罩）
+
上下文
+
可选文字提示
↓
生成模型
↓
重新生成目标区域
```

# 十四、最难的技术问题

## 14.1 算法难点

### 头发

需要 Image Matting（Image Matting，图像前景透明度估计），不能只做 0/1 二值分割。

### 半透明物体

玻璃、婚纱、烟、水、毛发等需要联合估计前景、背景和 Alpha（Alpha，透明度）。

### 阴影

人物移动和换背景后，原阴影可能失效，需要估计光源方向、光强、环境色和阴影关系。

### 反射

对象在玻璃、水面、桌面的反射会随位置变化，属于高级场景理解问题。

### 遮挡

系统需要理解前后关系，即 Layer Ordering（Layer Ordering，层级顺序估计）。

## 14.2 工程难点

### 大图

10000 × 10000 四通道 8 位图片，单份原始像素约 400MB。多个图层、历史、遮罩和缓存会迅速占用数 GB（Gigabyte，十亿字节级存储单位）内存。

### Tile（Tile，图像分块）

建议使用 256×256 或 512×512 分块，只重新计算变化区域。

### 多分辨率预览

拖动参数时先使用低分辨率预览，鼠标释放后再计算高质量结果。

### Undo/Redo（Undo/Redo，撤销/重做）

不要每次保存完整 Bitmap（Bitmap，位图），推荐 Command Pattern（Command Pattern，命令模式）+ 参数 + 变化区域。

# 十七、竞品研究方向

## Photoshop

优势：专业能力最深、生态成熟。  
不足：根本交互模型仍然以工具、参数、图层为主。

## Photoshop Elements

优势：快速操作和引导式编辑明显降低学习门槛。  
不足：仍然偏“引导流程”，不是完整对象驱动。

## Canva

优势：已经实现图片主体、前景和背景对象的自动分离，并支持直接移动、改色、删除和替换。  
风险：与本项目方向高度接近。  
机会：Canva 核心仍然是设计平台，不是深度、可逆、对象级像素编辑器。

## Photopea

优势：浏览器中高度接近 Photoshop。  
不足：解决访问成本，不解决学习成本。

## Pixelmator

优势：机器学习增强、背景移除、选择和超分辨率体验较好。  
不足：仍保留专业工具逻辑。

## Affinity Photo

优势：专业、性能好、图层和非破坏式编辑完整。  
不足：对小白仍有明显专业认知门槛。

## GIMP（GNU Image Manipulation Program，GNU 图像处理程序）

优势：免费开源、能力丰富。  
不足：典型工具驱动型产品。

## Fotor / Pixlr

优势：大量一键 AI（Artificial Intelligence，人工智能）编辑。  
不足：深度编辑和复杂多对象工作流有限。

## 美图秀秀 / 醒图

优势：人像和照片美化强，普通用户门槛低。  
不足：不是通用桌面对象级图像编辑系统。

## 稿定设计

优势：模板和商业视觉内容生产。  
不足：更偏在线设计平台。

## remove.bg

优势：证明复杂抠图可以压缩成一个按钮。  
不足：单点工具，缺乏对象后续编辑生命周期。

## Clipdrop

优势：移除、换背景、重打光、放大、扩图、文字移除等高度傻瓜化。  
不足：工具集合型明显，缺乏统一语义对象文档系统。

## Adobe Firefly

优势：生成式编辑能力成熟。  
不足：核心价值偏生成，并非完整普通用户桌面编辑器。

# 二十三、最终立项判断

## 1. 技术上是否可行

**可行。**

大部分单项能力已经存在成熟算法或成熟产品验证。

真正需要解决的是：

> 如何把它们组织成一个实时、可逆、统一的对象级编辑系统。

## 2. 是否值得立项

**值得。**

前提是不要做 Photoshop 克隆，而是重新定义普通用户操作图片的方法。

## 3. 是否存在真实需求

**存在。**

大量一键抠图、删除、背景替换、图片增强和生成式编辑产品已经证明用户愿意使用低门槛图像处理工具。
