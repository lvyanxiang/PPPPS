# MVP（Minimum Viable Product，最小可行产品）功能清单

## 目标

第一版不复制完整 Photoshop，而验证一件事：

> 用户是否可以在不理解图层、Mask（Mask，遮罩）、选区、通道和专业工具的情况下，通过“点击对象 → 选择目标”完成复杂图片处理。

## V1 必做

### 文件

1. 打开图片
2. 保存项目
3. 导出 JPEG（Joint Photographic Experts Group，常用有损图片格式）
4. 导出 PNG（Portable Network Graphics，便携式网络图形格式）

### 基础编辑

5. 裁剪
6. 旋转
7. 调整尺寸
8. 亮度
9. 基础颜色

### 核心对象交互

10. 自动识别主要对象
11. 鼠标悬停高亮对象
12. 点击选择对象
13. 自动生成 Mask（Mask，遮罩）

### 人物与背景

14. 人物抠图
15. 背景移除
16. 背景替换
17. 背景虚化

### 对象编辑

18. 对象移动
19. 对象缩放
20. 对象删除
21. 对象换色

### 智能增强

22. 图片增强

## 可选增强

23. 生成式填充
24. 生成式扩图

如果团队只有 1 人，建议把 V1 再缩减成：

1. 打开
2. 裁剪
3. 调尺寸
4. 点击对象
5. 人物抠图
6. 去背景
7. 换背景
8. 删除物体
9. 移动对象
10. 导出

## V1 明确不做

- PSD（Photoshop Document，Photoshop 文档格式）；
- 专业钢笔；
- 高级通道；
- CMYK（Cyan Magenta Yellow Key，青品黄黑印刷四色颜色模型）工作流；
- Camera Raw（Camera Raw，相机原始图像处理模块）；
- 视频；
- 动画；
- 插件；
- 脚本；
- 专业印刷；
- 高级绘画；
- 复杂文字排版；
- 专业商业海报编辑。

## MVP 成功判断标准

### 产品

- 小白用户可以不看教程完成抠图、换背景、删除物体；
- 用户不需要理解图层和 Mask（Mask，遮罩）；
- 主要操作入口以“对象”为单位，而不是工具。

### 技术

- 主要对象点击命中率足够高；
- 人物边缘可接受；
- 4K（4K，约四千像素级分辨率）图片基本可流畅交互；
- 20～50 次 Undo/Redo（Undo/Redo，撤销/重做）稳定；
- Windows 主流 GPU（Graphics Processing Unit，图形处理器）可以运行。

### 商业验证

- 用户愿意持续编辑，而不只是做一次抠图；
- 用户能理解“点击对象 → 操作”的产品范式；
- AI（Artificial Intelligence，人工智能）成本可以控制。
